# Offline Chess Game

This is an Offline Chess Game developed using React.js. Two players can play chess on the same computer by taking alternate turns. The game includes legal movement for chess pieces, check and checkmate detection, player timers, and move history.

## Features
- 8 × 8 Chess Board
- Two Player Offline Game
- Turn-Based Gameplay
- Legal Piece Movement
- Check Detection
- Checkmate Detection
- Player Timer
- Move History
- Undo Move

## Technologies Used
- React.js
- JavaScript
- CSS3
- HTML5

## How to Run
1. Install dependencies - npm install

2. Start the project - npm run dev

3. Open the browser - http://localhost:5173
